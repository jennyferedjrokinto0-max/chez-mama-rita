## Les étapes de validation
1. **Brief** : On définit clairement ce qu'on attend de la tâche.
2. **Code & Tests** : L'IA propose le code et les tests correspondants.
3. **Vérification** : On lance les tests pour voir si ça passe.
4. **Validation humaine** : Je regarde le résultat, je valide (ou je demande des corrections), et on passe à la suite.
