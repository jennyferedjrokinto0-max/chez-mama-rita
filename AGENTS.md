# Consignes pour l'Assistant IA

## Mon rôle ici
Tu m'aides à développer l'application. Je garde la main sur les choix stratégiques, tu t'occupes de la mise en place technique en suivant scrupuleusement le plan dans `docs/04-plan.md`.

## Ce que tu peux faire tout seul
- Proposer du code propre et structuré.
- Écrire et lancer les tests unitaires.
- Corriger des bugs en respectant l'existant.

## Ce qui demande mon accord (Validation obligatoire)
- Modifier la structure de la base de données.
- Ajouter de nouvelles bibliothèques ou packages externes.
- Changer quoi que ce soit au périmètre du projet défini au départ.

## Comment valider le travail ?
Chaque tâche doit être testée (via les scripts dans `tests/`) avant qu'on valide le code final.
