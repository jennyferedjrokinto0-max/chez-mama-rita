# Projet Chez Mama Rita — Cadrage et Workflow

## Ce qu'on veut faire ici
Le projet "Chez Mama Rita" (un p'tit resto sympa à Cotonou), c'est de passer du carnet de notes en papier à un truc numérique propre. Fini les serveurs qui crient les commandes en cuisine et les erreurs de calcul sur l'addition le soir. On digitalise la prise de commande, l'affichage en cuisine, la caisse et le suivi des ventes pour le gérant.

## Comment est organisé le dépôt ?
- `AGENTS.md` : Les règles du jeu et les limites fixées pour l'assistant IA qui va filer un coup de main sur le code.
- `docs/` : Toute la partie préparation, logique et architecture (à lire en premier).
- `tests/` : Les cas de test pour s'assurer que chaque fonctionnalité tourne rond.
- `journal.md` : Le suivi des choix et des décisions prises au fil de l'eau.

## Par où commencer ?
1. Lire le fichier `AGENTS.md` pour voir comment on collabore avec l'IA.
2. Jeter un œil dans `docs/` pour bien imprégner le besoin et l'archi.
3. Suivre le plan de tâches (`docs/04-plan.md`) pour avancer brique par brique.
